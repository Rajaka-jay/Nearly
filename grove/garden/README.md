# Nearly forest clearing

Generated with the built-in image generation tool on 27 November 2026; optimized to 1536 × 1024 WebP. Runtime configuration is `lib/assets.ts`. The central clearing intentionally has no baked-in tree so all five growth stages can share the environment.

Generation brief: landscape 3:2 detailed painterly romantic storybook forest; empty mossy central clearing for a separate tree; tall forest canopy at edges; warm peach sky with no sun disk; cottage and sleeping cat at far left; picnic basket/blanket at lower left; rope swing and lantern at right; winding stone path, ferns, grasses, flowers and pebbles. Cream, sage, peach, earthy brown, muted pink. No people, text, UI, logos, central tree or watermark.

Season/time overlays and particles are code layers rather than image variants.

Sprite prompts request a single centered full animal, warm detailed watercolor/gouache storybook texture, transparent background, no scenery, text, vector icon, watermark or logo. Optimized WebP versions preserve alpha and fit within 400 × 400. Runtime paths live in `lib/assets.ts`.
